GifScratcher

A lightweight, dependency-free JavaScript library that allows you to "scratch" GIFs.

Download GitHub

Demo

Move your mouse over the image to scratch it.

Documentation

Using a gif

Decoding uses the built-in ImageDecoder API where available (Chrome, Edge, Opera) and falls back to a pure-JS parser (gifuct-js) on Firefox and Safari. 

<div id="target"></div>
 
import { GifScratcher } from './javascripts/gifscratcher.js';

new GifScratcher('#target', {
  gif : 'animation.gif'
});

Settings

{
  gif    : string  // Real .gif to decode & scrub
  auto   : boolean // Autoplay
  scrub  : boolean // Scrub on hover / drag
  cursor : boolean // Add custom cursor
  player : boolean // Show transport controls
  speed  : number  // Playback speed multiplier
}

Using a sprite

A standalone sprite-strip version is included in the download as gifscratcher-sprite.js. Instead of decoding a .gif it translates a pre-built horizontal sprite strip on the GPU. Add the first frame as an <img /> 

<div id="target">
  <img src="animation-first.webp" />
</div>
 
import { GifScratcherSprite } from './dist/gifscratcher-sprite.js';

new GifScratcherSprite('#target', {
  sprite : 'animation.webp',
  frames : 10
});

Settings

{
  sprite      : string  // Image sprite
  frames      : int     // Number of frames in sprite
  interaction : string  // 'hover' | 'drag'
  auto        : boolean // Autoplay
  cursor      : boolean // Add custom cursor
  speed       : int     // Autoplay speed (rAF ticks per frame)
}

Creating a sprite

To extract every single frame from an animated GIF as individual JPEGs and create a sprite you can use ImageMagick in the terminal.

Install ImageMagick (macOS): brew install imagemagick

To extract the frames run: magick FILENAME.gif -coalesce %02d.webp

To create the sprite run: magick ??.webp +append FILENAME.webp
